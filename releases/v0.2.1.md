# Orbital v0.2.1 — Groups, updates, and interface refinements

## Repository groups restored

- Grouped repositories are back in the sidebar.
- Create, rename, and remove groups, and move repositories between groups from repository settings.
- Removing a group moves its repositories to another group without deleting files.
- Existing group assignments are preserved when available; flat v0.2.0 workspaces load into a default Workspace group.

## Quick in-app updates

- Checks for new published versions on startup and every 30 minutes, with a manual check in Preferences.
- Shows an **Update** button when a newer release is available.
- Downloads and verifies signed update packages, shows progress, and launches the installer after you click Update.
- Waits for pending Git operations before starting installation. On Windows, the app closes for installation and restarts afterward.

**Upgrading from v0.2.0 or earlier:** download and run this release's Windows setup `.exe` once. Those versions do not contain the updater. Future published, signed releases can be installed from inside v0.2.1 and later. Draft releases are not offered as updates.

## Interface improvements

- Custom dropdowns with keyboard navigation and colors matching the app.
- Themed scrollbars across panes, dialogs, and dropdowns.
- An additional branch-switch button in the bottom bar; the top branch control stays available.
- Prevented horizontal and vertical scrolling outside the app window. Long content scrolls inside its own pane.

Git must be installed and available on PATH. VS Code is required for external editor and diff actions. Updater signatures are enabled; Windows Authenticode signing is not configured.
