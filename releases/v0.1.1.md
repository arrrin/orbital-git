# Orbital v0.1.1 — Windows preview

This release fixes the Windows test failure that blocked the first preview installer and includes the initial Orbital feature set.

## Fixed

- Isolated test repositories from the machine's Git line-ending settings, fixing the stash test failure with Windows CRLF checkouts.
- Added regression coverage for stashing and restoring work with `core.autocrlf=true`.
- Added version-specific release notes to the generated GitHub release draft.

## Included

- Colored commit graph with merge connections, branch and tag labels, search, and commit details.
- Repository groups and a quick-switch sidebar with branch, changed-file, and ahead/behind indicators.
- Staged, unstaged, and historical diffs, with VS Code integration.
- Fetch, fast-forward pull, push, staging, commits, and stashes.
- Branch creation and switching, remote tracking, merge previews, rebase, tags, cherry-pick, and revert.
- Worktree creation, repository/editor shortcuts, and safe removal of clean worktrees.
- Conflict indicators and continue/abort controls.
- Command palette with `Ctrl/Cmd K` and refresh with `Ctrl/Cmd R`.

## Install

Download the Windows x64 setup `.exe` from **Assets**, run it, and open or clone a repository. Git must be installed and available on PATH. VS Code is needed for external editor and diff actions. Node.js, Rust, and C++ Build Tools are not required to run the installed app.

## Preview limitations

History displays the latest 500 commits. Staging works at the file level. Hunk staging, blame, Git LFS/submodule management, hosting-provider pull requests, interactive rebase editing, and a built-in three-way conflict editor are not included. Resolve conflicts in your editor, then stage and continue in Orbital.

Automatic in-app updates and Windows code signing are not configured. Download and run a newer installer to update.
