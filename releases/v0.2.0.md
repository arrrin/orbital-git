# Orbital v0.2.0 — A faster everyday workflow

## Faster staging

- Staging and unstaging move files immediately, with Git index writes queued in order.
- Lightweight working-status reads replace full history reloads after staging.
- Removed routine staging success popups and repeated “Repository updated” messages.
- Failed index operations restore the actual repository state and report the Git error.

## A simpler workspace

- Removed repository groups in favor of one flat sidebar. Existing repositories and names are preserved.
- Changes is now the default view when opening or switching repositories.
- Resize the repository sidebar, changed-file list, and graph inspector by dragging their dividers. Sizes are remembered. Arrow keys adjust dividers; double-click resets them.
- Right-click a repository, or use its options button, to open it, launch VS Code, reveal its folder, fetch, copy its path, rename it, or remove it from the workspace. Removing a repository keeps its files on disk.

## Preferences and background work

- Choose your interface font and font size in Preferences.
- Background fetch runs every five minutes by default. Choose another interval or turn it off in Preferences.
- Fetch runs quietly without pulling or switching branches. Fetch failures are visible in the sidebar and Preferences.
- Added subtle popup and view transitions, with an animation toggle and support for reduced motion.
- File diffs reload when selected again or when the app regains focus.

## Install or update

Download the Windows x64 setup `.exe` from **Assets** and run it. Git must be installed and available on PATH. VS Code is needed for external editor and diff actions. The installed app does not require Node.js, Rust, or C++ Build Tools.

Automatic in-app updates and Windows code signing remain unconfigured. History is limited to the latest 500 commits; staging is file-level, and conflicts are resolved in your editor.

[Report an issue](https://github.com/arrrin/orbital-git/issues).
