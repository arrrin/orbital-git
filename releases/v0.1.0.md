# Orbital v0.1.0 — First preview

Orbital is a local Git desktop client built with Rust and Tauri. This first preview brings your repositories, branch history, working changes, and worktrees into one dark, graph-focused workspace.

## Highlights

- **See your history:** colored commit graph with merge connections, branch and tag labels, search, branch filtering, and commit details.
- **Organize your repositories:** persistent groups and a quick-switch sidebar showing the current branch, changed files, and ahead/behind status.
- **Review changes in VS Code:** inspect staged, unstaged, and historical diffs. Unstaged diffs open the working file for editing.
- **Bring branches together:** choose a branch to merge into your current branch and preview the number of incoming commits.
- **Work in parallel:** create worktrees with new or existing branches, open them in Orbital or VS Code, and remove clean worktrees.

## Everyday Git tools

- Open, initialize, and clone repositories.
- Fetch, fast-forward pull, and push with upstream tracking.
- Create and switch branches, track remote branches, rebase, and delete merged local branches.
- Stage and unstage files, review text diffs, and create commits.
- Save and apply stashes, including untracked changes.
- Create tags, cherry-pick commits, and revert commits.
- Identify conflicts and continue or abort merge, rebase, and cherry-pick operations.
- Find actions and repositories with `Ctrl/Cmd K`; refresh with `Ctrl/Cmd R`.

## Install

1. Download the Windows x64 setup `.exe` from this release's **Assets**.
2. Run the installer and launch Orbital.
3. Open a local Git repository or clone one from a remote.

Git must be installed and available on PATH. Orbital uses your existing Git identity and authentication setup. Install VS Code to use the editor and external diff actions. The installed app does not require Node.js, Rust, or C++ Build Tools.

## Preview limitations

- Commit history currently displays the latest 500 commits.
- Staging works at the file level; hunk staging is not included.
- Resolve conflicts in your editor, then stage the files and continue in Orbital. A built-in three-way conflict editor is not included.
- Blame, Git LFS management, submodule management, hosting-provider pull requests, and interactive rebase editing are not included.
- Automatic in-app updates and Windows code signing are not configured. Install later versions by downloading their setup installer.
